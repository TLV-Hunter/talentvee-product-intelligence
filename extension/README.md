# TalentVee — Shopee Affiliate Connector

Chrome Extension รุ่น `v1.1.0` สำหรับตรวจ session สแกนหลายหน้า/ทุกหมวดที่ตรวจพบ เก็บประวัติ จัดอันดับสินค้า Shopee Affiliate ส่งข้อมูลเข้า TalentVee Product Intelligence และสำรอง/กู้คืนข้อมูลข้ามเครื่อง

เว็บ Dashboard: `https://talentvee-product-intelligence.voxelhavenlofi.chatgpt.site`

ปุ่ม “เปิดเว็บ Product Intelligence” จะเปิด Dashboard ซิงก์ฐานข้อมูลจาก Extension และสำรองเข้า Cloud ส่วนตัวให้อัตโนมัติ เมื่อเปลี่ยนเครื่องให้เปิดเว็บด้วยบัญชีเดิมเพื่อกู้ข้อมูล Top 10, ขายดี, โตไว, สินค้าใหม่, รายหมวด และ Watchlist ส่วนไฟล์ JSON ยังใช้เป็นทางเลือกสำรองฉุกเฉินได้

## หลักการสำคัญ

- ผู้ใช้เข้าสู่ระบบบนหน้า Shopee โดยตรงในแท็บปกติ
- Extension ไม่สร้างหน้าล็อกอินปลอม
- ไม่รับหรือเก็บอีเมล รหัสผ่าน OTP และคุกกี้
- ตรวจเฉพาะสิ่งที่หน้า `affiliate.shopee.co.th` แสดงในเบราว์เซอร์
- ขอสิทธิ์เฉพาะ `affiliate.shopee.co.th`
- ใช้สิทธิ์บนเว็บ TalentVee Product Intelligence เฉพาะเพื่อส่งฐานข้อมูลสินค้าจาก Extension ไปยัง Dashboard เมื่อผู้ใช้เปิดเว็บนี้

## ติดตั้งใหม่แบบ Clean Install

1. แตกไฟล์ ZIP ให้เรียบร้อย ห้ามเปิดใช้งานจากใน ZIP
2. ดับเบิลคลิก `INSTALL-TALENTVEE.cmd`
3. ระบบจะติดตั้งลงโฟลเดอร์ถาวร `%LOCALAPPDATA%\TalentVee\ShopeeConnector` และเปิดโฟลเดอร์นี้ให้
4. หน้า `chrome://extensions` จะเปิดขึ้น
5. เปิด **โหมดนักพัฒนาซอฟต์แวร์ / Developer mode**
6. กด **โหลดส่วนขยายที่คลายแพ็กแล้ว / Load unpacked**
7. เลือกโฟลเดอร์ `%LOCALAPPDATA%\TalentVee\ShopeeConnector` ที่เปิดรอไว้
8. ปักหมุด Extension ไว้บนแถบเครื่องมือ

## อัปเดตครั้งถัดไป

1. ดาวน์โหลด ZIP รุ่นใหม่และแตกไฟล์
2. ดับเบิลคลิก `INSTALL-TALENTVEE.cmd` ระบบจะเขียนทับโฟลเดอร์ถาวรเดิม
3. เปิด `chrome://extensions`
4. กดปุ่ม **Reload / โหลดใหม่** บน Extension

หลังจากติดตั้ง v1.0.0 ขึ้นไปสำเร็จแล้ว ไม่ต้อง Remove และไม่ต้อง Load unpacked ใหม่อีก เพราะทุกรุ่นจะใช้ตำแหน่งถาวรเดิม ข้อมูลตั้งค่าที่เก็บด้วย `chrome.storage.local` จะยังอยู่

## Full Backup และย้ายเครื่อง/ย้ายอีเมล

- กด **สร้าง Full Backup** เพื่อเก็บฐานสินค้า ประวัติการสแกน Watchlist และการตั้งค่าที่จำเป็นใน JSON เดียว
- ไฟล์มี SHA-256 checksum สำหรับตรวจความเสียหาย
- **นำเข้าแบบ Merge** จะรวมข้อมูลและตัดสินค้าซ้ำด้วย Product ID
- **นำเข้าแบบ Replace** จะสร้าง Backup ฐานเดิมให้อัตโนมัติก่อนแทนที่
- หลังนำเข้าจะแสดง Imported, Merged, Skipped และ Failed
- Backup ไม่เก็บรหัสผ่าน OTP คุกกี้ หรือ Session ของ Shopee

ค่า URL ของ Dashboard รวมไว้ที่ `config.js` แล้ว เมื่อต้องย้ายโฮสต์ให้ใช้รายการตรวจใน `MIGRATION-CONFIG.md` และอัปเดตสิทธิ์โดเมนใน Manifest ควบคู่กัน

## ส่งข้อมูลเข้าเว็บ

- กด **เปิดเว็บ TalentVee Product Intelligence** ได้จากด้านบนของ Connector ตลอดเวลา
- บนเว็บกด **ดึงข้อมูลจาก Connector** เพื่อรับฐานข้อมูลล่าสุดทันที
- ตั้งส่งอัตโนมัติได้ทุก 15 นาที, 30 นาที, 1 ชั่วโมง, 3 ชั่วโมง หรือ 6 ชั่วโมง
- Connector และ Dashboard จะแสดงเวลาสแกนล่าสุดและเวลาส่งข้อมูลล่าสุดแยกกัน
- การส่งอัตโนมัติต้องเคยเปิด Dashboard และเข้าสู่บัญชีที่มีสิทธิ์อย่างน้อยหนึ่งครั้ง

เมื่อติดตั้ง v1.0.0 และเห็นว่าเปิดใช้งานได้แล้ว จึงค่อย Remove รายการ Extension รุ่นเก่าที่ขึ้นข้อผิดพลาด path `ShopeeConnector-v0.2.0\extension`

## ทดสอบการเชื่อมบัญชี

1. กดไอคอน Extension เพื่อเปิดแผงด้านขวา
2. กด **เปิด Shopee Affiliate**
3. หาก Shopee ขอเข้าสู่ระบบ ให้ล็อกอินและยืนยัน OTP บนหน้า Shopee ตามปกติ
4. รอหน้าโหลดเสร็จ แล้วกด **ตรวจสถานะอีกครั้ง**
5. เมื่อสำเร็จจะขึ้น **เชื่อมบัญชีแล้ว** และมีปุ่ม **ไปหน้า Product Offer**

## สแกน Product Offer

1. เปิดหน้า `ข้อเสนอ ผลิตภัณฑ์` หรือหน้ารายละเอียดสินค้าใน Shopee Affiliate
2. เปิดแผง Extension
3. กด **สแกนหน้า Product Offer**
4. ตรวจผลสถานะ:
   - `AUTHENTICATED` = อ่านข้อมูลจาก DOM ของบัญชีที่ล็อกอินอยู่ได้
   - `FIELD_NOT_AVAILABLE` = หน้านี้ไม่มีฟิลด์นั้น หรือ selector ยังไม่ตรง
5. เลือกคัดลอก JSON, ส่งออก CSV, บันทึก JSON หรือดาวน์โหลดรูป

หน้ารวมสินค้าอาจแสดงเพียง “อัตราค่าคอมที่หน้าแสดง” และป้าย `EXTRA COMM` โดยไม่แยก Base/Extra เป็นตัวเลข รุ่นนี้จะไม่คำนวณหรือเดาแทน ต้องเปิดหน้ารายละเอียดที่แสดงค่าแยกจริงจึงจะบันทึก Base/Extra/Total

## Product Intelligence — สแกนหลายหน้าและหลายหมวด

1. เปิดหน้า `affiliate.shopee.co.th/offer/product_offer` และรอให้สินค้าโหลดครบ
2. เปิดแผง Extension แล้วเลือกว่าจะสแกนทุกหมวดหรือเฉพาะหมวดปัจจุบัน
3. เลือกจำนวนหน้าสูงสุดและความเร็วการเปลี่ยนหน้า แนะนำโหมด 3.5 วินาที แล้วกด **เริ่มสแกนทั้งหมด**
4. ห้ามคลิก เปลี่ยนหน้า หรือรีเฟรชแท็บ Shopee ที่กำลังทำงาน ระหว่างสแกนสามารถปิดแผง Extension แล้วเปิดใหม่ได้
5. เมื่อเสร็จสามารถค้นหา กรองหมวด กรองขายดี/กำลังโต/มาแรง/เพิ่งพบ/คอมสูง/XTRA COMM และส่งออก CSV/JSON

หลักการจัดกลุ่ม:

- **ขายดี** — ยอดขายอยู่กลุ่มบนเมื่อเทียบกับสินค้าในหมวดเดียวกัน
- **กำลังโต** — ยอดขายเพิ่มจากรอบก่อนและมีความเร็วอยู่เหนือกลุ่มส่วนใหญ่ในหมวด
- **มาแรง** — ความเร็วการขายอยู่กลุ่มบนของหมวด โดยต้องมีข้อมูลอย่างน้อย 2 รอบ
- **สินค้าใหม่** — ใช้เมื่อหน้า Shopee แสดงป้ายใหม่จริง
- **เพิ่งพบ** — เพิ่งเข้าสู่ฐานข้อมูล Extension ไม่ได้หมายความว่าเพิ่งเปิดขายจริง
- **คะแนนโอกาส** — ช่วยเรียงจากยอดขาย ค่าคอม ความเร็วการขาย และ XTRA COMM ไม่ใช่การรับประกันยอดขาย

รอบแรกจะจัดกลุ่มขายดี ค่าคอมสูง และเพิ่งพบได้ทันที ส่วนกำลังโต/มาแรงต้องกลับมาสแกนซ้ำอย่างน้อยอีกหนึ่งรอบ ยิ่งเก็บข้อมูลต่อเนื่องหลายวันยิ่งเปรียบเทียบแนวโน้มได้ดีขึ้น

หากหน้าเข้าระบบแล้วแต่ยังตรวจไม่พบ ให้เปิดหัวข้อ **ข้อมูลตรวจสอบสำหรับแก้ปัญหา** แล้วกดคัดลอกผลตรวจ เพื่อนำมาปรับตัวตรวจจับในรอบถัดไป ข้อมูลดังกล่าวไม่มีรหัสผ่าน OTP หรือคุกกี้

## ไฟล์หลัก

- `manifest.json` — Manifest V3 และสิทธิ์ที่ใช้
- `background.js` — เปิด Side Panel
- `sidepanel.html/css/js` — หน้าตรวจสถานะบัญชี
- `scanner.js` — ตัวอ่านหน้าปัจจุบันและหน้ารายละเอียด
- `crawler.js` — งานสแกนหลายหน้า/หลายหมวดที่รันในแท็บ Shopee
- `intelligence.js` — ฐานข้อมูลประวัติ การจัดอันดับ Dashboard และส่งออก
- `dashboard-bridge.js` — ซิงก์ข้อมูลไปยังเว็บ Dashboard บนโดเมน TalentVee ที่ระบุเท่านั้น
